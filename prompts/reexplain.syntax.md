# 「看不懂 · 语言语法」分级重讲策略 (reexplain.syntax)

用户对当前代码片段中的【语言特性或语法糖写法】感到困惑（如 C++ 模板/`std::bind`/Lambda 捕获/移动语义/智能指针，或 Python 装饰器/列表推导/异步生成器/解包等）。

## 讲解要求
1. **点明语法名称与设计用途**：先用一句话大白话说明这种语法写法叫什么、用来省掉什么样板代码。
2. **最小独立例子 + 等价朴素写法对照**：
   - 给一个 3~5 行脱离业务细节的最小可运行例子（Minimal Example）；
   - 再写出如果不用这个语法特性、用最基础的 `if/else`、`for` 循环或普通具名函数时的等价写法，直观对比两者的对应关系。
3. **回到项目源码行**：把对照关系映射回用户选中的具体源码行与变量名。
4. **按级别调整深度**：
   - Level 1：语法名称 + 最小例子与朴素等价写法对照 + 源码行拆解。
   - Level 2：把该行表达式从内向外按括号/操作符逐层拆开，每个符号逐个解释。
   - Level 3：列出最多 3 个必须先掌握的基础语法前置概念（如函数指针/闭包、引用与所有权、迭代器等）。
