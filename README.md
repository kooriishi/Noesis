# NOESIS

> 代码学习型桌面 IDE —— 让 AI 深度解读大型代码仓库，解决「通用 AI 讲大型项目太泛、没有深度」的问题。

---

## 核心设计理念

1. **结构先于讲解**：先用静态分析（Tree-sitter + LSP）算出项目的真实结构（依赖图、调用图、入口点），再让模型在确定性结构上逐层精读，每一句话都具备源码依据。
2. **四层视角**：
   - **整体**：职责边界、系统位置、数据流向
   - **逻辑**：控制流、状态变迁、边界条件、设计权衡
   - **语法**：语言特性、惯用写法、泛型与宏
   - **原理**：底层算法、通信协议、操作系统机制
3. **分层下钻（先短后长）**：按「项目 $\to$ 模块 $\to$ 调用链 $\to$ 函数」渐进展开，单卡片先提供一句话和关键要点，点击展开出细节。
4. **外发控制 (P0)**：模型出口统一，自动排除敏感配置/证书/密钥，支持内容脱敏与发送前预览。
5. **双端支持**：跨 Windows 11 与 Linux (Ubuntu 22.04 LTS 等) 平台。

---

## 技术架构

- **宿主底座**：Tauri 2 (WebView2 on Windows, WebKitGTK on Linux)
- **前端核心**：React + TypeScript + Vite + CodeMirror 6 (带官方 LSP 客户端及解读气泡/阅读标记扩展)
- **后端内核 (Rust)**：多 Crate 架构
  - `project`: 项目导入、文件树管理、目录监听、忽略规则
  - `indexer`: Tree-sitter 解析、符号与引用抽取、项目拓扑图
  - `lsp`: 语言服务器进程生命周期管理与 JSON-RPC 消息路由
  - `llm`: 统一模型网关（多提供方适配、流式输出、外发过滤与脱敏）
  - `learn`: 学习单元编排、解读卡片、出题批改、艾宾浩斯复盘调度
  - `runner`: 子进程草稿运行沙盒
  - `store`: SQLite 本地数据访问与迁移
- **存储引擎**：SQLite

## 工程目录结构规划

```text
Noesis/
├─ src-tauri/crates/     # Rust 内核 crate
│  ├─ project/           # 导入、文件树、监听、忽略规则
│  ├─ indexer/           # tree-sitter 解析、符号与引用、项目图
│  ├─ lsp/               # 语言服务器进程管理与消息转发
│  ├─ llm/               # 模型网关:多提供方适配、流式输出、外发过滤
│  ├─ learn/             # 学习单元、解读卡片、练习、复盘调度
│  ├─ runner/            # 草稿运行(子进程)
│  └─ store/             # SQLite 访问与迁移
├─ src/                  # 前端
│  ├─ shell/             # 整体布局、命令面板、主题
│  ├─ editor/            # CodeMirror 6 扩展:解读气泡、阅读标记
│  ├─ sidebar-project/   # 文件、地图、路线
│  ├─ sidebar-ai/        # 聊天、解读、练习
│  └─ scratch/           # 临时子窗口
├─ prompts/              # 智能体提示词 (纯文本, 版本化)
├─ eval/                 # 解读质量评测集与脚本
└─ docs/                 # 规划与设计文档
```

## 开发路线图 (Roadmap)

- [ ] **M0 地基**：Tauri 2 + React + TS 工程骨架、按 crate 划分内核、CodeMirror 6 编辑器、文件树、双端 CI
- [ ] **M1 项目地图**：Tree-sitter 符号索引、LSP 引用调用图、阅读路线规划
- [ ] **M2 解读引擎**：模型网关、外发控制、分层摘要、四层解读卡片、「看不懂」标记与重构讲法
- [ ] **M3 练习复盘**：草稿沙盒、出题与批改、错题本、间隔复习与学习档案
- [ ] **M4 打磨补全**：AI 内联补全、调用链图可视化、多窗口形态与性能压测
- [ ] **M5 公司适配**：代理与自签证书、内网模型适配、外发审计日志、双端发布包
