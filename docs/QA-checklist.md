# Noesis 跨平台交付验收清单 (`docs/QA-checklist.md`)

本清单用于在 Windows 10/11 与 Linux (Ubuntu 22.04+) 环境下对 Noesis 进行交付前质量验收。

## 1. 安全与红线审计 (P0)
- [ ] **仓库零硬编码密钥**：执行 `git grep -E "sk-[A-Za-z0-9]{20,}"` 与 `git log -p -S "sk-"`，确认工作区与历史提交中无真实 API Key 或个人邮箱。
- [ ] **密钥安全存储**：在设置中保存 API Key 后，检查浏览器 DevTools `localStorage` 中不包含任何 `api_key` 明文；重启应用后密钥状态仍保持 `has_api_key: true`。
- [ ] **路径穿越防护**：尝试调用 `read_file` 或 `save_file` 传入 `../../outside.txt`，确认在创建任何目录前即被拒绝并返回安全错误。
- [ ] **敏感文件拦截**：尝试打开或通过 Agent 工具读取 `.env`、`id_rsa`、`secret.pem`，确认被 `OutboundFilter` 阻断。
- [ ] **完全离线模式**：勾选「完全离线模式」后，确认所有模型调用被立即阻断，且代码浏览、AST 索引、ROS2/LLM 拓扑图、两阶段阅读路线、确定性练习题与 SM-2 复习均可正常使用。

## 2. 编辑器与 UI 性能体验 (Stage E1)
- [ ] **DPI 缩放适配**：在 Windows 100% / 125% / 150% / 200% 缩放比例下，三栏拖拽分隔条、顶部工具栏与浮动选区菜单无错位或文字截断。
- [ ] **中文输入法 (IME) 兼容**：在编辑器与右侧「智能问答」输入框中使用中文拼音输入法，按 `Enter` 候选上屏时不会误触发发送消息（`!e.nativeEvent.isComposing`）。
- [ ] **20 个标签页切换与状态保持**：连续打开 10~20 个代码文件并来回切换，确认光标位置、滚动条位置与撤销栈（`Ctrl+Z`）完整保留，无闪烁或卡顿。
- [ ] **大文件保护 (`> 1 MB`)**：打开超过 1 MB 的源码或日志文件，确认顶部展示只读保护横幅并保持流畅滚动；点击「仍然完整打开」后可切换为完整编辑模式。
- [ ] **选区浮动工具栏边界夹紧**：在编辑器最顶部第一行、最底部一行及最右侧边缘选中文本，确认「深度解读 / 看不懂 / 沙盒运行」气泡自动翻转或夹紧，不被容器边缘裁切。

## 3. 工程分析与领域识别 (Stage B + E2)
- [ ] **示例项目验证 (`RobotVoiceWS-main`)**：打开示例项目并触发索引，确认自动识别 `ros2` 与 `llm_app` 领域，提取出完整的符号表、调用边、ROS2 节点/话题以及阅读路线。
- [ ] **两阶段阅读路线持久性**：在阅读路线中将某一步标记为「已读 (`done`)」，重新点击「索引工程」，确认已读状态不会丢失。
- [ ] **LSP 符号跳转与回退**：在未安装外部语言服务器（`clangd` / `pyright` / `rust-analyzer`）的机器上，确认自动回退至 Tree-sitter + `DbStore` 静态索引并提供定义/引用定位与置信度标识。

## 4. 四层深度解读、引用核验与练习闭环 (Stage C + D)
- [ ] **P0–P7 上下文清单抽屉**：生成四层解读后，点击「上下文清单」按钮，确认展示 P0–P7 各层 Token 占用、裁剪状态、注入的内置知识包 ID 以及 `basis_hash`。
- [ ] **引用真实性程序化核验 (`CitationVerifier`)**：确认卡片底部的源码引用徽章显示 `✓ 已核验`、`✓ 已修正行号`、`⚠ 引用待核实` 或 `📖 知识卡`，点击代码引用徽章可精确跳转并高亮对应源码行。
- [ ] **渐进式「看不懂」重讲 (Level 1 -> 2 -> 3)**：在「看不懂答疑」中点击「再换讲法 (L2/L3)」，确认使用递进降维策略；点击「看懂了」后状态更新为 `resolved` 并同步刷新个人学习画像摘要。
- [ ] **50+ 轮长对话预算压缩**：在「智能问答」中创建多个独立会话并进行多轮问答，确认历史预算自动裁剪并生成滚动摘要，不会超出模型上下文窗口。
- [ ] **间隔重复复习 (SM-2)**：完成自动生成的事实题或完形填空题后，确认根据答题质量分更新下次复习时间（1 天 -> 6 天 -> 15 天，答错重置为 1 天）。
