# NOESIS v0.1.3 — 四层解读接入与 Linux 索引修复版 (Windows & Linux)

本版本按第五轮修复方案（H1 – H5）逐条落地，修复了「后端做了、前端没接」类问题，并针对 Linux 版的索引锁、数据目录、浏览器启动方式做了实际验证。全部修复均在 Linux 版实际运行验证，Windows 侧通过 `cargo test --workspace` 与 Tauri 打包验证。

---

## 🌟 核心修复 (H1 – H5)

### H1 四层解读真正接入新流程
- 前端从旧的 `explain_selection_structured`（单次 JSON）切换到 `explain_layer`：**四层并发独立调用**，每层独立维护 `loading / streaming / done / error` 状态，逐字流式输出；
- 新增 `LayerCard` 组件：直接渲染整段 Markdown，卡片头显示层名、状态、已生成字数与质检结果，右上角可重新生成 / 复制，底部提供「这层还是没懂」与有用 / 太泛 / 有误反馈；
- 二级标题在内容较长时自动折叠（默认展开前两节），语法层的逐行注释 JSON 渲染为「行号 | 代码 | 注释」三列表格，原理层判定为「不适用」时折叠为一行灰字；
- **拆分冲突提示词**：`rules.locked.md` 拆为 `rules.safety.md`（安全与引用，四层/答疑/问答共用）与 `rules.json_v2.md`（旧 JSON 格式规则，仅旧流程使用）。`explain_layer` 不再拼接旧版 `code_guide_expert.system.md` 与 JSON 四视角规则，并在系统提示词末尾加上单层硬性输出约束；
- 删除 `explain_layer` 中重复构造的 `system_prompt` / `context_prompt` 代码块；
- 结果按 `basis_hash + layer + model + PROMPT_VERSION` 落缓存；**同一选区的四层共享同一个 `group_id`**，历史卡片档案可整组打开；
- 引用解析：从 Markdown 中提取 `[L12-L18]` / `[path:L40-L52]`，交由 `CitationVerifier` 用真实文件内容核验，前端渲染为可点击徽章。

### H2 修复 Linux 版「索引正在进行中」
- **启动不再默认打开 `./`**：改为恢复「最近一次打开的项目」，没有记录则停留在欢迎页（导入按钮 + 最近项目列表），启动时不会静默索引整个家目录；
- `IS_INDEXING` 进程级全局锁替换为按项目管理的 `IndexJob`（`project_id` / `cancel` / `processed` / `total` / `phase`）；
- 索引器每处理一个文件检查一次取消标志，被取消返回 `IndexerError::Cancelled` 且不写 `project_map`；
- 切换到新项目时自动取消旧项目索引；**同一项目重复点击不再报错**，返回「已在索引中」状态；
- 索引完成时校验项目是否仍是当前项目，不是则丢弃结果，避免旧项目地图覆盖新项目；
- 新增 `get_index_status` 与 `cancel_index`，前端每秒轮询显示进度条与「已处理 N / M 个文件」，并提供取消按钮；
- `open_project` 拒绝 `$HOME`、文件系统根目录、`/usr` 等系统级大目录，并给出明确中文提示。

### H3 智能问答布局修复
- 消息区改为独立滚动容器（`flex: 1; min-height: 0; overflow-y: auto`），输入栏固定在底部，不再被消息顶走；
- 快捷问题行隐藏横向滚动条，与输入框之间留出间距；
- 输入框由单行 `<input>` 改为 1–6 行自动增高 `<textarea>`：Enter 发送、Shift+Enter 换行，保留中文输入法 `isComposing` 判断；
- 生成中发送按钮切换为「停止」，调用 `cancel_llm_request`；
- 四层解读页与看不懂答疑页的顶部工具条固定，只有内容区滚动。

### H4 恢复主题与字体设置，并让设置真正生效
- 设置面板恢复「配色主题」（Catppuccin Mocha / One Dark Pro / Dracula / Tokyo Night / Catppuccin Latte 浅色）与「等宽字体族」「界面字体族」「行高」「Tab 宽度」；
- `tokens.css` 为 5 套主题定义完整 CSS 变量，通过 `:root[data-theme=...]` 切换，`ShellLayout` 根据设置写入 `document.documentElement.dataset.theme`；
- 扫描并替换组件中写死的十六进制颜色为 `var(--noesis-…)`，**硬编码色值从 614 处降至 7 处**（剩余为 mermaid 运行时读取 CSS 变量的兜底默认值）；
- CodeMirror 主题随设置切换，mermaid 图形按当前主题重新初始化；
- 设置持久化改到后端应用数据目录的 `settings.json`，Linux 版换端口不再丢失设置；读取失败时才回退 `localStorage`。

### H5 其他问题
- **数据目录统一**：Linux 版回到 `~/.local/share/com.noesis.ide`，与 Tauri 标识一致；启动时若新目录没有数据库而旧目录有，自动迁移数据库与凭据文件；
- **浏览器启动方式**：优先以 `google-chrome` / `chromium` / `chromium-browser` / `microsoft-edge` / `brave-browser` 的 `--app=<url> --window-size=1280,840` 独立窗口打开，全部失败才回退 `xdg-open`；
- **看不懂答疑改走后端**：前端不再自行拼提示词，改为调用流式的 `explain_confusion`，输出按七个固定小节渲染；
- **智能问答接入工具循环**：`ask_project_question` 在 `use_tools` 为真时运行只读工具循环（读文件 / 搜索 / ROS2 拓扑 / 大模型应用分析），每一步工具调用通过 Channel 实时推送到前端；
- **HTTP 请求解析重写**：先循环读到 `\r\n\r\n`，再按 `Content-Length` 读满请求体，修复请求头超过 8KB 或 TCP 分包落在请求头中间时解析失败导致的偶发「Invalid JSON」。
